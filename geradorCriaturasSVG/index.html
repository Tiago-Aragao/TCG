Como usar no seu jogo

Deixe index.html e criaturas.js na mesma pasta e abra o HTML no navegador. O catálogo mostra um exemplar de cada subtipo; escolha um subtipo para comparar variações.

// SVG como string, no navegador ou em Node.js:
gerarSVG("robo-insetoide", { seed: "carta-42" });
gerarSVG("Mortos-Vivos", {
  subtipo: "zumbi-arqueiro",
  genero: "F",
  seed: "carta-43",
  fundo: false
});

// Elemento <img> pronto para usar no navegador:
document.body.append(gerarCriatura("nave-viva", { seed: "nave-1" }));

// Em Node.js:
const { gerarSVG, SUBTIPOS } = require("./criaturas.js");

A mesma combinação de tipo, seed e opções repete a arte nesta versão. TIPOS, SUBTIPOS e NOMES_SUBTIPOS expõem o catálogo. Também são aceitos nomes com acento e espaços, como "robô insetoide", e os atalhos "zumbi-homem" e "zumbi-mulher".

Sem instalação, fontes ou imagens externas. O download inclui apenas a ilustração, sem textos ou moldura de carta.
